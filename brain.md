# 🧠 База знаний проекта CHARISMA (для Antigravity)

Этот файл служит контекстным хранилищем для работы в среде Antigravity. Здесь собрана основная информация о проекте `CHARISMA` на основе предыдущих диалогов. 

## ⚽ О проекте CHARISMA
Сайт виртуального футбольного клуба `CHARISMA`, выступающего в режиме Pro Clubs в EA FC (платформа Cyberfootball.online).
Сайт состоит из двух основных компонентов:

1. **Фронтенд (Визуальная часть)**:
   - Стек: Чистый HTML (`index.html`), Vanilla CSS (`styles.css`), JS (`script.js`).
   - Дизайн: Премиальный, "кинематографичный". Использованы particles bg (частицы на фоне), плавные blur-эффекты, золото и темные тона. Недавно прорабатывалась секция Hero для идеального отображения и контраста.
   - Данные для отображения (состав, лига, кубки, расписание, трофеи) подтягиваются из локальных JSON файлов в папке `data/`.

2. **Бэкенд / Сбор данных (Парсер)**:
   - Скрипт `update-data.js` написанный на Node.js с использованием Puppeteer.
   - Задача: Автоматически заходить на сайт турнира `cyberfootball.online`, скрапить актуальную статистику команды, лиги и трофеев, и сохранять результаты в `data/*.json`. Недавно парсер был доработан для извлечения **полных (не обрезанных) описаний трофеев**, где скрипт заходит внутрь каждого достижения для получения полного текста.
   - Автоматизация: Настроен GitHub Actions (`.github/workflows/update-data.yml`), который запускается по cron ежедневно (15:00 и 00:00 МСК) для обновления статистики.
   - Также есть ручной механизм обновления через `UPDATE_SITE.bat` (используется `basic-ftp` для хостинга Hostland).

## 📂 Обзор последних обсуждений и другого контекста

Помимо проекта CHARISMA, мы обсуждали и работали над следующими задачами (если они снова всплывут в работе, этот контекст поможет):

1. **Telegram Bot Auth & Ограничение доступа**:
   - Задача по переходу с обычного виджета логина Telegram на полноценную авторизацию через Telegram Bot (Deep Linking) с использованием Webhooks.
   - Ограничение действий (комментирование, голосование в опросах) для неавторизованных пользователей с автоматическим вызовом окна входа.

2. **Сайт Tandyr для рынка Германии**:
   - Анализ существующего сайта на Tilda (`tandyr.tilda.ws`).
   - Планирование переноса/адаптации под немецкий (и английский) рынки с интеграцией немецких платежных систем и полноценной админ-панелью. Стратегия маркетинга и продаж для старта.

3. **Бизнес-аналитика проектов**:
   - Разработка структуры и анализ бизнес-модели, IT-инфраструктуры, маркетинга и юридической базы для стартапа по заказу и продаже премиальных кастомных автомобильных дисков из Китая.
   - Вопросы по анализу потребления токенов (Token Usage Analysis) и технические лекции по работе парсеров.

## 🛠️ Правила для Antigravity

Если мы дорабатываем код или дизайн на этом сайте:
1. **Эстетика**: Только премиум дизайн. Без скучного минимализма. Любые изменения в `styles.css` должны поддерживать кинематографичность, glassmorphism, использовать правильную иерархию и современные анимации. НЕ используем Tailwind (если не попросят иначе).
2. **Парсинг**: При изменениях в `update-data.js` помнить, что скрипт зависит от верстки cyberfootball.online. При крашах нужно проверять селекторы.
3. **Релизы**: Данные обновляются ботом через GitHub Actions. Если меняем структуру JSON, нужно обновить и фронт (`script.js`), чтобы не сломать отображение.
