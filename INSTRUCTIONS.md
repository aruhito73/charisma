# Инструкция по обновлению сайта CHARISMA

Эта папка содержит скрипт для автоматического сбора данных с сайта `cyberfootball.online` и их загрузки на ваш хостинг Hostland.

## ⚙️ Подготовка (сделать один раз)

1. **Установите Node.js**
   - Скачайте и установите **LTS версию** с официального сайта: [https://nodejs.org/](https://nodejs.org/)
   - При установке просто нажимайте «Next» (Далее).

2. **Настройте доступ к хостингу**
   - Откройте файл `update-data.js` через блокнот или любой текстовый редактор.
   - Найдите блок `// ===== FTP CONFIGURATION =====` (строка 21).
   - Впишите туда данные вашего FTP от Hostland:
     ```javascript
     const FTP_CONFIG = {
         enabled: true, // ПОСТАВЬТЕ true
         host: "ftp.hostland.ru",
         user: "ваш_логин",
         password: "ваш_password",
         remoteDir: "/www/vash-sait.ru/data" // путь к папке data на сервере
     };
     ```
   - Сохраните файл.

## 🚀 Как обновлять данные

1. Просто запустите файл **`UPDATE_SITE.bat`** (двойным кликом).
2. Откроется черное окно (консоль). Дождитесь надписи **«УСПЕХ»**.
3. Скрипт сам скачает актуальный состав, таблицу лиги, календарь матчей и отправит всё на сайт.

---

### Что делать, если не работает?
- **Окно закрывается сразу:** Скорее всего, не установлен Node.js.
- **Ошибка FTP:** Проверьте логин и пароль в файле `update-data.js`.
- **Ошибка Puppeteer:** Проверьте, открывается ли сайт [cyberfootball.online](https://cyberfootball.online) в обычном браузере.
